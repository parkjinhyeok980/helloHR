# hello,HRD

'hello,HRD'는 안전교육, 보건교육 등 사내 필수 교육 진행 과정을 디지털화, 자동화하는 시스템입니다.
교육 대상자는 더 이상 교육 확인 서명을 위해 긴 줄을 설 필요가 없고, 
교육 담당자는 수기 서명을 받고 스캔하고 보고서에 붙혀넣는 과정을 간소화 할 수 있습니다. 

https://hello-hrd.vercel.app/
