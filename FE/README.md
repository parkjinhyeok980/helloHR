# hello,HRD 프런트엔드

Vue 3와 Vite로 만든 교육 운영 MVP 화면입니다. `docsimg`의 관리자 화면과 모바일 참여자 흐름을 참고했습니다.

## 실행

프로젝트 루트에서 Django 서버를 먼저 실행합니다.

```powershell
.\venv\Scripts\Activate.ps1
cd BE
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

별도 터미널에서 프런트엔드를 실행합니다.

```bash
cd FE
npm ci
npm run dev
```

## 데모 흐름

1. 교육 관리에서 교육을 만듭니다.
2. 대상자 관리에서 사번·이름·부서를 한 명씩 등록하거나, 엑셀 명부를 업로드합니다. 명단에서 수정·삭제할 수도 있습니다.
3. 출석 관리에서 참석 여부를 확인하거나, 상단의 **참여자 화면 보기**에서 이름과 교육별 4자리 출석 코드를 입력합니다.
4. 결과 보고서에서 참석/미참석 현황을 확인하고 인쇄 창에서 PDF로 저장합니다.

교육과 대상자 명단은 Django API와 SQLite에 저장됩니다. `seed_demo`는 예시 교육 3건과 대상자 명부를 중복 없이 생성합니다.

대상자 정보(사번·이름·부서)를 수정하면 동일한 사원이 등록된 다른 교육 명단에도 반영됩니다. 명단에서 삭제하면 해당 교육의 등록과 출석 기록만 삭제되고 사원 정보와 다른 교육 등록은 유지됩니다.

엑셀은 `.xlsx` 형식이며 첫 행에 **사번, 이름, 부서** 열이 필요합니다. 화면에서 빈 양식을 다운로드할 수 있습니다. 사번의 앞자리 0을 유지하려면 해당 열을 엑셀에서 텍스트 형식으로 입력하세요. 한 번에 최대 1,000명, 파일 크기는 최대 5MB입니다.

출석 상태는 아직 브라우저 `localStorage`에 저장되는 데모이며 다른 브라우저와 공유되지 않습니다. QR 출석과 전자서명도 아직 연결되지 않았습니다.
